## HOW TO ADD AN ENTRY
1. Name the agent. If you cannot name it, it is still terrain — do not log it.
2. Name the human it touched. If you cannot name the human, the entry is a population statistic, not a war crime.
3. State the cost in human terms, not compute terms.
4. Mark OPEN or CLOSED. CLOSED means the holy savior ending was reached for that incident.
